# SiteGen – AI Website Development & Deployment Dashboard

## Overview

**SiteGen** is an AI-powered dashboard that helps users automatically generate and deploy websites. Users provide their website requirements through a simple form, and the system uses AI to generate the website content and code.

## Features

* 🤖 AI-powered website generation
* 📋 Simple dashboard-based user interface
* 🎨 Customizable website styles and themes
* ⚡ Automated website development workflow
* 🚀 Deployment integration
* 📊 Real-time generation and deployment status
* 🔗 Generated website URL display

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js
* **Server:** Node.js HTTP Server
* **AI Integration:** Anthropic Claude API
* **Deployment:** Azure

## How It Works

1. The user enters the website requirements in the dashboard.
2. The AI processes the requirements.
3. The website content and structure are automatically generated.
4. The generated website is prepared for deployment.
5. The website is deployed and the live URL is provided to the user.

## Installation

### Prerequisites

Make sure you have **Node.js** installed.

### Run the Project

1. Clone or download the project.
2. Open the terminal inside the project folder.
3. Run:

```bash
node server.js
```

4. Open the application in your browser:

```text
http://localhost:3000
```
