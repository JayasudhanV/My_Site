Sentimental Analysis of Twitter Comments on Covid-19

Introduction

This project aims to analyze the sentimental analysis of Twitter comments on Covid-19.

  • Sentimental analysis is a technique used to determine the emotional tone or attitude conveyed by a piece of text.
  • Twitter comments are a valuable source of data for sentimental analysis, as they provide a large amount of text data that can be analyzed.
  • Covid-19 is a global pandemic that has affected millions of people worldwide, and Twitter comments can provide insights into how people are feeling about the pandemic.

Methodology

This project uses a combination of natural language processing (NLP) and machine learning techniques to analyze the sentimental analysis of Twitter comments on Covid-19.

  • Text data is collected from Twitter using APIs or web scraping techniques.
  • The text data is then preprocessed to remove stop words, punctuation, and other unwanted characters.
  • The preprocessed text data is then fed into a machine learning model to classify the sentimental analysis of the text.

Results

The results of the sentimental analysis of Twitter comments on Covid-19 are presented in the following sections.

  • The results show that the majority of Twitter comments on Covid-19 are negative, indicating a high level of anxiety and fear among the public.
  • The results also show that the sentimental analysis of Twitter comments on Covid-19 varies by region, with some regions showing more positive sentiment than others.
