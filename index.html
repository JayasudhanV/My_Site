How many opportunities are lost and what are the reasons?

SELECT reason_lost, COUNT(*) AS lost_count FROM opportunities_monthly_snapshot WHERE reason_lost IS NOT NULL GROUP BY reason_lost ORDER BY lost_count DESC;

What is the average contract duration (in months)?

SELECT AVG(contract_duration_months) AS avg_contract_duration FROM opportunities_monthly_snapshot;

How has the opportunity pipeline changed month over month?

SELECT modifiedmonthdate AS month, SUM(tcv) AS pipeline_value FROM opportunities_monthly_snapshot WHERE modifiedmonthdate IS NOT NULL GROUP BY modifiedmonthdate ORDER BY modifiedmonthdate;

Which sales leaders manage the highest pipeline value?

SELECT business_unit, SUM(acv_converted) AS pipeline_value FROM opportunities_weekly_snapshot GROUP BY business_unit ORDER BY pipeline_value DESC;

Which client geographies contribute the highest pipeline value?

SELECT client_geo, SUM(acv_converted) AS total_pipeline FROM opportunities_monthly_snapshot GROUP BY client_geo ORDER BY total_pipeline DESC;

What is the pipeline distribution by opportunity stage?

SELECT sales_leader, SUM(acv_converted) AS total_pipeline FROM opportunities_monthly_snapshot GROUP BY sales_leader ORDER BY total_pipeline DESC;

What is the total converted ACV for all opportunities?

SELECT SUM(acv_converted) FROM opportunities_monthly_snapshot;

What is the total pipeline ACV by capability for the latest week?

SELECT capability, SUM(acv_converted) / 1000000.0 AS total_pipeline FROM opportunities_weekly_snapshot GROUP BY capability;

What is the pipeline distribution across opportunity stages

SELECT os.Stage, SUM(oli.acv_converted) / 1000000.0 AS pipeline_value FROM opportunity_line_item_snapshot oli JOIN opportunity_stages os ON oli.stage_id = os.ID GROUP BY os.Stage ORDER BY pipeline_value DESC;

What is the total pipeline ACV for open opportunities

SELECT SUM(oli.acv_converted) / 1000000.0 AS active_pipeline FROM opportunity_line_item_snapshot oli JOIN opportunity_stages os ON oli.stage_id = os.ID WHERE os.Stage NOT IN ('Closed Won', 'Closed Lost');

How much pipeline ACV was dropped?

SELECT SUM(oli.acv_converted) / 1000000.0 AS dropped_pipeline FROM opportunity_line_item_snapshot oli JOIN opportunity_stages os ON oli.stage_id = os.ID WHERE os.Stage IN ('Dropped', 'Dropped');
